# BusyCat 개발 종료 · 재개 안내

정리일: 2026-09-12

## 프로젝트 상태

현재 기능 범위에서 적극적인 개발을 종료합니다. 추가 기능, 정기 업데이트,
문의 응답이나 수정 일정을 약속하지 않습니다. 필요하면 이후 개발을 재개할 수
있도록 소스와 검증 절차를 남깁니다. GitHub 저장소를 읽기 전용으로 아카이브하는
것과는 별개입니다.

배포 정책: Apple Silicon / macOS 13 이상, 무료 소스 공개, 미공증 배포.
Developer ID 발급·공증은 진행하지 않았으며 향후 필수 작업으로 약속하지 않습니다.
최종 공개 버전과 배포 파일은 GitHub Releases에서 확인합니다. 이 문서의 작성만으로
새 릴리스가 게시된 것은 아닙니다.

최종 배포 준비본은 **1.1.6**입니다. 1.2.0은 계획하지 않습니다.
릴리스 주소: https://github.com/mangomandu/busycat/releases/tag/v1.1.6
DMG 빌드 커밋: `a5005d6273ad0fbf70f43cc3863b76508942598c`.
최종 태그에는 Cask 해시와 문서 기록이 추가됩니다. 앱 소스·버전은 빌드 커밋과 같습니다.
파일: `BusyCat-1.1.6-macOS.dmg`
SHA-256: `98babb604697e50c9216a3c91c64c6f3929eaae0c9f25520cab741cec94de6bf`
해당 파일 생성 후 테스트 35개 및 DMG 내부 체크섬 검사를 통과했습니다.
새 파일은 기존 공개 1.1.5 파일을 대체하지 않습니다.

1.1.6 재현 시에는 `./make_dmg.sh --unnotarized-release`를 사용합니다.
이 경로는 미공증을 명시적으로 선택하고도 깨끗한 커밋·테스트·최종 해시 검사를 유지합니다.
빌드 직후 이전 Cask 해시와 달라 검사가 실패하는 것은 정상적인 준비 단계이며,
파일을 확인해 해시를 갱신한 후 재빌드 없이 검사만 실행합니다.

## 지금까지 완료한 작업

1. `99bd033` — 감사 지적사항 수정, 필요한 항목만 측정하는 경로, 업데이트 응답
   처리, 설치 교체 및 배포 스크립트 안전장치 보완.
2. `15f9f29` — 추가 감사 지적사항, 버전 파싱·측정값 예외 처리·라이선스 포함·
   자동 검사 보완.
3. `c15978f` — 측정 중단 후 CPU/GPU 평균 초기화, 잠자기 전 그래프와 늦게 도착한
   측정 결과 무효화, 언어 변경 중 업데이트 메뉴 복구, IPv6 줄바꿈,
   SP78 온도 부호 해석, 외부 명령 출력 대기 문제, 로컬 DMG 파일명 분리.
4. `d43fd85` — 최종 DMG와 Homebrew Cask의 실제 SHA-256 비교 및 실패 처리.
5. `078a6f2` — 공식 패키징 전 깨끗한 커밋·테스트 통과 확인, 패키징 중 변경 감지.

위 변경까지 로컬 앱에 설치했습니다. 당시 표시 버전은 1.1.5이며, 공개된 1.1.5와
수정 내용이 같다는 뜻은 아닙니다. 설치 파일의 실제 내용은 커밋과 해시로 구분합니다.

## 확인한 것 / 확인하지 않은 것

확인한 내용:

- `078a6f2` 기준 테스트 35개 통과. 해시 검사와 배포 사전 검사는 각각 6개 조건을 검사.
- 배포용 빌드, Swift 동시성 검사, 스크립트 문법·버전 정보 검사 통과.
- 한국어·영어 기본 패널과 긴 IPv6 주소의 줄바꿈 확인.
- 업데이트 확인 중 메뉴 재생성 후 실패·최신 버전·새 버전 결과별 복구 확인.
- 로컬 앱 교체·재실행, 코드 서명 유효성, 빌드/설치본 실행 파일 해시 일치 확인.

미검증 또는 범위 제한:

- 실제 장시간 사용, 반복 잠자기·복귀, 재부팅 후 로그인 자동 실행.
- macOS 13 실기기에서의 전체 동작. 최소 지원 버전 설정과 실행 검증은 다릅니다.
- 다양한 Apple Silicon 기종의 GPU·온도 센서 정확도. GPU 연산 부하는 추정값이고
  온도 센서 이름과 제공 여부는 기종/OS에 따라 달라집니다.
- Developer ID 서명·공증·새 Mac의 Gatekeeper 검증. 미공증으로 인한 첫 실행 차단은
  알려진 배포 제약입니다. 보안 기능 전체를 끄도록 안내하지 않습니다.
- 테스트 통과는 모든 버그가 없다는 보장이 아닙니다.

## 구조 빠르게 보기

- `Sources/BusyCat/AppDelegate.swift`: 메뉴바 UI, 설정, 업데이트 메뉴, 잠자기/복귀.
- `SamplingCoordinator.swift`: 직렬 측정 큐와 깨어 있는 구간별 그래프 상태.
- `UsageReader.swift`: CPU/GPU/메모리/디스크/네트워크/배터리/온도 수집.
- `MetricMath.swift`, `SMCValueDecoder.swift`: 측정 계산과 온도값 해석.
- `StatsView.swift`: 상세 패널 렌더링. `AppUIModels.swift`: 표시 옵션·언어.
- `Updater.swift`: GitHub 최신 릴리스 조회와 버전 비교. 자동 설치는 하지 않음.
- `Tests/BusyCatTests/BusyCatTests.swift`: 회귀 테스트.
- `make_app.sh`: 앱 빌드, 선택적으로 /Applications 교체·재실행.
- `make_dmg.sh`: DMG 패키징. `--local`은 개발용 파일명으로 분리.
- `tools/check_release_consistency.sh`: 버전·문서·Cask 확인, 최종 파일 해시 대조.
- `tools/check_release_preflight.sh`: 깨끗한 커밋 및 테스트 통과 확인.

## 나중에 재개할 때

1. 저장소의 AGENTS 지침을 읽고 `git status`, 최근 로그, GitHub Releases를 확인합니다.
   미커밋 사용자 변경을 덮어쓰지 않습니다.
2. 마지막 공개 태그와 현재 HEAD를 비교합니다. 공개 DMG, 작업 폴더의 앱,
   /Applications 앱이 서로 다른 시점일 수 있습니다.
3. `./test.sh`를 실행합니다. 제한된 실행 환경에서 SwiftPM 샌드박스 중첩 문제가
   있을 때만 해당 환경의 권한 절차에 따라 `./test.sh --disable-sandbox`를 사용합니다.
4. 문제가 보고됐다면 재현 조건(기종, OS, 설정, 잠자기 여부)을 먼저 확보하고
   재현 테스트와 최소 수정부터 진행합니다. 새 기능·대규모 재설계는 필수가 아닙니다.
5. 설치가 필요할 때만 `./make_app.sh --install`을 실행합니다. 실행 중 앱을 종료하고
   /Applications의 사본을 교체하므로 사용자의 설치 의사를 먼저 확인합니다.

## 다음 배포 체크리스트

- 기존 공개 태그와 설치 파일을 덮어쓰지 말고 새 버전을 사용합니다.
- Info.plist의 두 버전, Cask 버전, 두 README 다운로드 링크를 맞춥니다.
- 깨끗한 커밋에서 테스트 후 DMG를 만듭니다. 미공증 상태는 명확히 표시합니다.
- 최종 파일을 확정한 다음 Cask 해시를 갱신합니다. 다시 빌드하면 파일 해시가
  바뀔 수 있으므로 같은 파일을 대상으로 검사를 재실행합니다.
- `./tools/check_release_consistency.sh --artifact <최종-DMG-경로>`를 통과시킵니다.
- 소스 커밋·태그·릴리스 노트·업로드 파일을 연결하고 업로드 후 해시를 확인합니다.
- 새 버전의 Cask를 공개할 때 다운로드 URL이 실제로 존재하는지 확인합니다.
- 실제 배포 성공 여부와 최종 버전은 GitHub Releases를 기준으로 확인합니다.
